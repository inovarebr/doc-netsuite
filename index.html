Visão geral do conector

Este guia apresenta as principais telas e funcionalidades do conector Netsuite, facilitando o entendimento do fluxo de uso do sistema.

Após fazer login, o acesso será redirecionado para a tela de dashboard, conforme demonstra a imagem a seguir.

Menu lateral

O menu lateral concentra os principais pontos de navegação do conector.

Como podemos ver, o menu lateral possui poucos botões.

O primeiro botão com ícone de casa é para acessar o dashboard. O segundo botão, que chamamos de menu hambúrguer (3 traços), é para acessar o menu principal e o terceiro botão é para trocar o idioma do conector.

Dentro do menu hambúrguer há diversas opções que serão exploradas mais adiante.

Os outros dois botões no menu lateral são para alternar entre modo claro/escuro e acessar os dados do usuário, respectivamente.

Menu principal

Ao acessar o menu principal veremos duas opções principais de navegação.

Ao acessar o menu principal veremos 2 opções:

Administrativo geral que serve para configurar o conector. Esse menu nem sempre estará disponível para todos os usuários.

Agendamentos é onde criamos as requisições para o conector fazer as extrações não Infor.

Idioma

Detalhe do que aparece quando o botão de idioma é clicado.

Ao clicar no botão de idioma, o conector exibe uma lista com os idiomas disponíveis. Basta selecionar a opção desejada para que a interface seja ajustada automaticamente.

Perfil

Na opção Ajuda, somos direcionados para uma página com a documentação do conector.

Em Meus Dados, é possível ajustar o cadastro do usuário e escolher algumas opções de segurança, que veremos em detalhes a seguir.

A opção Segurança serve para realizar a troca da senha.

Meus dados

Suas informações pessoais ajudam a manter sua conta segura e personalizada.

Aqui você pode atualizar seu nome, e-mail e outras informações básicas para garantir que nossa comunicação seja feita corretamente e que suas preferências sejam respeitadas.

Suas informações profissionais definem o ambiente de trabalho dentro do sistema.

Selecione a organização e a empresa que você deseja gerenciar, isso garante que os dados, acessos e relatórios exibidos estejam vinculados corretamente à sua estrutura corporativa.

As informações complementares permitem personalizar sua experiência no sistema.

Você pode habilitar recursos adicionais, como a autenticação em dois fatores (2FA), para reforçar a segurança do seu acesso e proteger seus dados contra uso indevido.

Agendamentos

Área em que acompanhamos as cargas que estão sendo realizadas e o histórico do que já foi executado.

Ao acessar a página de agendamento, é possível visualizar os agendamentos configurados, consultar o status de execução e iniciar novos processos de integração de dados.

Quando não há agendamentos cadastrados para o período, o sistema exibe uma mensagem destacando essa condição e oferece a opção de adicionar um novo agendamento.

Novo agendamento

As opções do agendamento são:

  • Frequência: define se o agendamento irá ocorrer apenas uma vez ou de forma recorrente. Caso seja recorrente, será aberta a opção para escolher a frequência e o momento da execução.
  • Objeto de Integração e Tipo de Objeto: serve para escolher o tipo de dado a ser carregado, por exemplo, dados cadastrais ou modelos de documentos fiscais.
  • Empresa: indica em qual empresa buscar os dados.
  • Período da Carga: quando a carga tem um período (documento fiscal, inventário, contábil etc.), é possível determinar o intervalo de datas que deve ser considerado.
  • Número de Documento: útil quando deseja integrar apenas um documento fiscal específico.
  • Integrar todos os registros: disponível apenas na versão 1 do extrator. Quando marcada, reintegra todos os dados desde o ID de processo zero; quando desmarcada, apenas os dados nunca recebidos são integrados.
