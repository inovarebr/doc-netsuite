# Agent for HTML/MD Synchronization

## Purpose
This custom agent automatically synchronizes MD files with their corresponding HTML pages in any subdirectory. It creates new HTML pages when they don't exist (based on `modelo.html` template) or updates existing HTML table content to match MD file data.

## When to use this agent
Use this agent when you:
- add new MD files to any subdirectory under `mapeamento/`
- edit existing MD files with table data
- need to sync MD table content with HTML display
- need to detect changes specifically in `mapeamento/cadastros/` and create or update the corresponding HTML page

## Available Skills
This agent leverages the following skills from `.skills/`:

### **MD to HTML Converter Skill**
**Location:** `.skills/md-to-html-converter/`

**Purpose:** Converts Markdown table data into complete HTML pages with visual identity matching `modelo.html`

**When agent invokes this skill:**
- Creating new HTML files from MD source
- Converting MD table structures to HTML format
- Applying consistent styling (colors, gradients, footer)
- Generating responsive HTML with proper CSS

**Skill Features:**
- Parses markdown tables and extracts row/column data
- Generates complete HTML with DOCTYPE, meta tags, and inline CSS
- Preserves visual identity: gradients (#4a86e8, #3367d6, #c9daf8, #a4c2f4)
- Includes standard footer with Compliance copyright and Inovare branding
- Handles special characters, line breaks, and formatting
- Applies CSS classes (.condicao, .obrig-sim, .obrig-nao) automatically
- Creates responsive designs for all screen sizes

**Skill Documentation:**
- `SKILL.md`: Technical documentation and specifications
- `USAGE_EXAMPLE.md`: Practical examples with input/output
- `QUICK_REFERENCE.md`: Quick guide and checklist

## What this agent does

### 1. **File Detection & Mapping**
   - Monitors MD files added/edited in `mapeamento/cadastros/`
   - Locates the corresponding HTML file with the same name in the same directory
   - If HTML file exists → proceed to update mode
   - If HTML file doesn't exist → proceed to creation mode

### 2. **HTML Creation (when file doesn't exist)**
   - **Invokes:** MD to HTML Converter Skill from `.skills/md-to-html-converter/`
   - Passes: MD table content, page title, section header, filename, output path
   - Skill returns: Complete HTML file with all styling and footer applied
   - Creates new HTML file using skill output
   - Preserves all styling: color scheme, gradients (#4a86e8, #3367d6, #c9daf8, #a4c2f4)
   - Includes footer with Compliance copyright and Inovare branding
   - Page title: MD file name (capitalized appropriately)
   - Section header: Auto-generated based on MD content context
   - Table structure: Automatically generated from MD table

### 3. **HTML Update (when file exists)**
   - **Invokes:** MD to HTML Converter Skill (if table structure needs regeneration)
   - Parse the MD file to extract table data
   - Extract the HTML file's existing table structure
   - Map MD table rows to HTML table rows
   - Update cell contents while preserving HTML formatting and classes
   - Maintain all styling, colors, and layout
   - Apply skill recommendations for class assignments and formatting

### 4. **MD Table Format Expectations**
   - MD files should contain a markdown table with columns
   - Common column patterns:
     - `#` or `ID` - row identifier
     - `WS Compliance`, `Conector`, `API Netsuite` - field mappings
     - `Condição / Regra` - conditional rules or observations
   - Table rows are mapped 1:1 to HTML table rows
   - Skill handles proper escaping of special characters

### 5. **HTML Table Structure to Preserve**
   - Keep `<thead>` with column headers unchanged
   - Update only `<tbody>` row content
   - Preserve all CSS classes (`.condicao`, `.obrig-sim`, `.obrig-nao`, etc.)
   - Maintain border styling and alternating row colors
   - Keep responsive design intact
   - Skill ensures consistency with modelo.html standards

### 6. **Style Consistency Rules**
   - **Header**: Use gradient background `linear-gradient(135deg, #4a86e8, #3367d6)`
   - **Section headers**: Use gradient `linear-gradient(135deg, #c9daf8, #a4c2f4)`
   - **Table headers**: Use `#e8effb` background with `#1f2937` text
   - **Alternating rows**: Use `#f7f9fc` for even rows
   - **Footer**: Include copyright and Inovare branding with consistent styling
   - **Font**: Use 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif
   - **Skill enforcement:** Skill automatically applies all color/style rules

### 7. **Applicable Subdirectories**
   - Works in any subdirectory under `mapeamento/`
   - Examples: `cadastros/`, `nfe/`, `cte/`, `nfse/`, `nfsc/`, `contabil/`, `inventario/`, `retidos/`, `bloco_k/`
   - Automatically detects subdirectory context and applies appropriately
   - Skill generates paths relative to subdirectory location

## Skill Integration Workflow

```
User creates/edits .md file
         ↓
Agent detects change
         ↓
Agent checks for corresponding .html file
         ↓
    ┌─────────────────────────┐
    │                         │
    ├─ HTML exists?      HTML doesn't exist?
    │                         │
    └─ Update mode      Creation mode ───→ Invokes MD to HTML Converter Skill
                               │
                               ├─ Skill parses MD table
                               ├─ Skill generates complete HTML
                               ├─ Skill applies colors & styling
                               ├─ Skill adds footer
                               └─ Skill returns generated HTML
                                      ↓
                         Agent saves HTML file
                                      ↓
                         Page ready with visual identity
```

## Implementation Notes
- When editing MD files, ensure table format is consistent with markdown standards
- Column alignment: use `|` separators and `---` for dividers
- Special characters in cells: skill handles escaping automatically
- Conditional/rule cells: skill preserves formatting and converts line breaks to `<br>`
- If skill cannot process MD format, agent falls back to manual HTML creation with modelo.html template
- All generated files match skill output specifications from `.skills/md-to-html-converter/SKILL.md`
