📌 O que é um Conector de Integração

Em termos simples, um Conector de Integração (ou Middleware) é um sistema que atua como uma ponte ou gestor de fluxo de dados entre dois softwares diferentes, garantindo que as informações saiam de um banco de dados e entrem no outro corretamente.

No cenário ERP (Oracle Netsuite) → Inovare Soluções (Conector) → Compliance Soluções (Final):

Componente Função no Processo
ERP Oracle Netsuite É a Fonte de Dados. Onde as informações de cadastros, documentos fiscal, contabilidade são geradas
Conector da Inovare Soluções É o Middleware. Acessa via API o ERP, processa as informações e as envia para o destino.
Compliance Soluções É o Destino. Recebe os dados processados para fins fiscais.

O Conector garante que os dados armazenados no Oracle Netsuite sejam transferidos com segurança e precisão para o banco de dados da Compliance Soluções.

Para acessar, informe o Email e senha fornecidos pelo Inovare e, em seguida, clique em "Entrar". Você também pode optar por "Faça login com o Google".

⚙️ 2. Configurações Iniciais

Após o login, você pode alterar algumas configurações na tela inicial:

2.1. Alterar o Idioma

Para alterar o idioma, vá para "Tela Inicial/botão Idioma".

🖼️ [Imagem do Seletor de Idioma]

  • Selecione "Inglês" ou "Espanhol".
  • O idioma padrão é o português do Brasil.

2.2. Selecionar a Cor da Tela ("Modo da tela")

Para alterar o modo de exibição, vá para "Tela Inicial/botão Escuro".

  • Selecione "Escuro" para ativar a tela escura.
  • O padrão é o modo claro.

👤 3. Menu Administrativo e Ações

O Menu Administrativo inclui opções para alterar foto, Ajuda, Meus dados, Segurança e Sair.

3.1. Alterar Foto (Avatar)

Para alterar a foto do avatar, clique em cima da foto do avatar.

🖼️ [Imagem do Menu do Avatar]

  • Escolha a nova foto.
  • Selecione o check para aceitar a nova foto, ou excluir para cancelar.

3.2. Acessar a Base de Conhecimento

Para acessar a base de conhecimento, clique em "Ajuda".

  • A opção "Ajuda" permite "Acesse a base de conhecimento".

3.3. Acessar Dados Pessoais

Para acessar os dados pessoais, clique em "Meus Dados".

🖼️ [Imagem da Tela Meus Dados]

  • A opção "Meus Dados" permite ver as "Configurações do seu usuário".
  • O perfil exibe Informação Pessoal como Nome, Sobrenome, E-mail, Sexo, além de Informações Complementares e Autenticação 2FA.

3.4. Alterar Senha

Para alterar a senha, clique em "Segurança". Esta opção permite "Cadastrar uma nova senha".

🖼️ [Imagem da Tela de Alteração de Senha]

  • Primeiramente, informe a senha atual por questões de segurança.
  • Em seguida, entre com a nova senha e clique em "Validar".

3.5. Sair da Aplicação

Para sair da aplicação, clique em "Sair".

  • Será exibida a mensagem: "Você deseja realmente sair?".
  • Clique em "Confirmar" para desconectar ou "Cancelar" para permanecer na aplicação.

💡 Nota: Mantenha suas credenciais de acesso em local seguro e não compartilhe com terceiros. Caso tenha dúvidas ou problemas de acesso, entre em contato com o suporte da Inovare Soluções.
